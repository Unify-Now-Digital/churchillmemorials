# Churchill Memorials — "Request a Quote" → GoHighLevel Field Mapping

**Purpose:** Turn every website *Request a Quote* email into a clean GoHighLevel (GHL)
**Contact** + **Opportunity**, automatically and consistently.

**Source email:** subject `[Request a quote]`, from `no-reply@churchillmemorials.co.uk`
→ delivered to `info@churchillmemorials.com`. Generated by the WooCommerce
*Request a Quote* plugin on churchillmemorials.co.uk.

---

## 1. What the quote email actually contains

Every quote email carries the same blocks. Field inventory:

| Block | Raw field | Example (Quote #9982) | Always present? |
|---|---|---|---|
| Header | Quote number | `Request a Quote #9982` | Yes |
| Product row | Product name + size | `The Manor - 6ft 6" x 2ft 6"` | Yes |
| Product row | SKU | `#16074-02` | Yes |
| Product row | Quantity | `1` | Yes |
| Product row | Line subtotal | `£3,447.25` | Yes |
| Item meta | Pick A Memorial Colour | `Standard - Black` | Usually |
| Item meta | Pick Lettering Colour | `Gold` | Usually |
| Item meta | Flower Container | `Two Vases` | Sometimes |
| Item meta | Photo Plaque | `Heart plaque (+£160.00)` | Sometimes |
| Item meta | Garden Kerbset / add-ons | `Garden Kerbset (+£295.00)` | Sometimes |
| Item meta | Choose infill | `White (+£250.00)` | Sometimes |
| Item meta | **Inscription** | `In loving memory of Deana Oates…` | Usually |
| Totals | Order **Total** | `£3,447.25` | Yes |
| Message | Customer's message | free text (optional) | Sometimes |
| Details | **First Name** | `Montana` | Yes |
| Details | **Last Name** | *(blank)* | Often blank |
| Details | **Email** | `sprangxxx@gmail.com` | Yes |
| Details | **Phone** | `07440608169` | Usually |
| Details | **Grave Location** | `SW17 0BY Blackshaw Road Tooting` | Sometimes |
| Details | **Grave Number** | *(blank)* | Often blank |

Notes that matter downstream:
- **Last name is frequently empty** — customers often type only a first name.
- **Order Total is WooCommerce's auto-calculated figure.** It excludes the cemetery
  **permit fee** and is not Churchill's final quoted price (the team re-quotes). Treat it
  as the *initial opportunity value*, to be confirmed.
- The **deceased's name and occasion** are not their own fields — they live *inside the
  Inscription text* and must be parsed out.
- **Grave Location** is a free-text mix of postcode / street / cemetery — not a clean
  cemetery name.

## 2. Classification schema (the 8 requested fields)

How each requested field is derived from the raw email:

| # | Classified field | Derived from | Rule / logic |
|---|---|---|---|
| 1 | **First name** | `First Name` detail | Direct. If blank, parse from Inscription salutation or leave blank. |
| 2 | **Last name** | `Last Name` detail | Direct. Frequently blank — do **not** invent one. |
| 3 | **Order value** | `Total` | Strip `£`/commas → number. Flag as *website estimate, permit fee not included*. |
| 4 | **Order type** | Product name + SKU | Classify into a fixed set (see below). |
| 5 | **Cemetery** | `Grave Location` (+ inscription) | Normalise free text → cemetery name + postcode. Infer where possible; keep raw. |
| 6 | **Occasion** | Inscription text | Parse relationship/deceased → memorial occasion (e.g. "Memorial for a mother"). |
| 7 | **Inscription** | `Inscription` item meta | Verbatim, line breaks preserved. |
| 8 | **Additional notes** | Item meta + Customer's message + Grave Number + add-ons | Concatenate all colour/lettering/plaque/infill/add-on options, deceased DOB/DOD, customer message, and grave number into one notes blob. |

**Order type** — normalise the product into one value (aligns with ClickUp "Job Type"):

| If product name / SKU suggests… | Order type |
|---|---|
| Headstone, "3ft", "2ft 6"", book/scroll/ogee designs | `New memorial – Headstone` |
| Kerb set, "The Manor", "6ft 6" x 2ft 6"", kerbset, full grave | `New memorial – Kerb set` |
| Cremation tablet / desk / plaque | `New memorial – Cremation tablet` |
| Additional inscription / add a name / renovation | `Renovation / additional lettering` |
| Cleaning / restoration | `Cleaning / restoration` |

## 3. GHL mapping — CONTACT

Standard GHL contact fields (API names) + recommended custom fields.

| GHL Contact field | Type | Source | Notes |
|---|---|---|---|
| `firstName` | standard | First Name | |
| `lastName` | standard | Last Name | leave empty if blank |
| `email` | standard | Email | **dedupe key** — upsert on email |
| `phone` | standard | Phone | E.164 normalise (`+44…`) |
| `source` | standard | — | constant: `Website – Request a Quote` |
| `tags` | standard | — | add **`raq`** (existing GHL tag), plus `new-enquiry` |
| `cf_grave_location` | custom | Grave Location | free text |
| `cf_grave_number` | custom | Grave Number | often blank |

> The customer's **own postal address is not captured** by this form, so contact
> address fields stay empty. Grave Location is memorial data, not the contact's address —
> keep it in a custom field, not `address1`/`city`.

**Upsert rule:** match on `email`; if the contact exists, update phone/tags and attach a
new opportunity rather than duplicating the contact.

## 5. Custom fields to create in GHL (one-time setup)

Contacts: `Grave Location`, `Grave Number`.

Opportunities: `Quote Number`, `Product`, `SKU`, `Order Type`, `Deceased Name`,
`Occasion`, `Cemetery`, `Grave Number`, `Memorial Colour`, `Lettering Colour`,
`Photo Plaque`, `Infill`, `Add-ons`, `Inscription`, `Additional Notes`.

(If you'd rather keep the GHL object lean, the minimum viable set is: `Quote Number`,
`Order Type`, `Cemetery`, `Inscription`, `Additional Notes` — the rest can live in the
notes blob.)

## 6. How to wire it up (automation outline)

Recommended: **Make** (already connected) or n8n.

1. **Trigger** — Gmail: new email, from `no-reply@churchillmemorials.co.uk`,
   subject `[Request a quote]`.
2. **Parse** — extract the fields in §1 from the HTML body (the structure is fixed:
   the `Customer's details` block and the `wc-item-meta` list are reliable anchors).
3. **Classify** — apply §2 rules (order type, occasion, deceased name, cemetery normalise).
4. **GHL upsert Contact** — match on email (§3).
5. **GHL create Opportunity** — pipeline = Churchill sales, stage = New Enquiry (§4).
6. **(Optional) mirror to ClickUp** CM: Orders as status *new enquiry* to keep the
   authoritative order record in sync.

Guardrails:
- Never overwrite a non-empty last name with a blank.
- Keep `monetaryValue` flagged as an estimate; the team confirms the real quote + permit fee.
- Ignore obvious test submissions (e.g. inscription = "Test Order").
